# Actions and automation

This is the heart of Cuebot. Here you learn how to make Cuebot do things by itself: thank a follower, switch a scene,
post a link every 15 minutes, or react to a key you press.

## What's in here

- [How actions work](how-actions-work.md): the ideas. Actions, triggers, sub-actions, branches, variables and queues.
- [Your first action](your-first-action.md): build a raid welcome click by click, and test it.
- [The action editor](action-editor.md): every button, menu and shortcut of the list editor (the **Sub-actions** tab).
- [The flowchart editor](flowchart.md): the node editor. See and change an action as boxes and lines.
- [Logic and branches](logic-and-branches.md): If, Switch, loops, groups, random picks, delays and doing things at once.
- [Variables, the %words%](variables.md): put names, numbers and saved values into your messages.
- [Queues](queues.md): make actions wait their turn, so alerts play one at a time.
- [History](history.md): see what ran, what started it, and every event that came in.
- [Timers](timers.md): start actions on a clock.
- [Hotkeys](hotkeys.md): start actions with a keyboard shortcut, even while a game is in front.
- [Watchers](watchers.md): start actions when a file, a log or a program on your computer changes.
