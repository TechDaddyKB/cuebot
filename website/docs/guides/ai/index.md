# The AI assistant

Cuebot can use an AI (a computer program that understands text) to help you set things up. You type what you want in
plain words, like "make a !lurk command", and the AI builds it for you. The AI only helps *you*: it never talks to
your viewers.

## What's in here

- [The setup assistant](assistant.md): chat with an AI inside Cuebot, and let it build actions, commands and timers.
- [The assistant on your own computer](local-models.md): use a free AI that runs on your own computer, with Ollama or
  LM Studio.
- [Using your own AI app with Cuebot (MCP)](ai-apps.md): let an AI app you already use, like Claude Desktop or
  Claude Code, work on Cuebot.
