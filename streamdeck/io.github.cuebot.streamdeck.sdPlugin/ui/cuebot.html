In Cuebot open the Stream Deck page (or Servers → REST API), turn the REST API on and copy the token. Host and port are Cuebot's REST API (default 127.0.0.1:7475).

Cuebot's Stream Deck sub-actions (Set Title, Set State, Set Background...) target keys by this id. Keys with the same id change together.

Presses, releases, dial turns and touches fire the Stream Deck Action trigger in Cuebot with %buttonId%, %buttonEvent%, %ticks% and these arguments.
